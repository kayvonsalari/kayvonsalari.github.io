Healthcare Intelligence Assistant

Lets clinicians ask questions of their data in plain English, safely.

01The problem

When a doctor wants to know something from hospital data, such as how many patients on a certain drug were readmitted, they usually have to ask a database specialist and wait. Letting AI write database queries directly would be faster, but one wrong query could change or delete patient records.

02What it does

Clinicians type their question in everyday language. The system turns it into a database query (this is called Natural Language to SQL) and returns the answer. Before anything runs, it sorts the query into one of three groups:

  • Read: it only looks at data, so it runs straight away.
  • Write: it would change data, so a person must approve it first.
  • Unsafe: it could cause harm, so it is refused.

03How it works

The sorting step sits in front of the database like a gatekeeper. Every question, query and decision is logged, so there is a full record of who asked what and what happened. That record is what keeps the system within health data rules such as HIPAA in the US and GDPR in Europe.

04What came out of it

Clinicians get answers in seconds without waiting for a specialist, and the database stays protected. The same gatekeeper idea applies to any company that wants staff to query their own data without risk.
