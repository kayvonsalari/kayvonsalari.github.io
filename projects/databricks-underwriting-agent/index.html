Mortgage paperwork to decision on Databricks

An agent that reads loan documents, catches what does not add up, and leaves the decision to fixed rules and a person.

01The problem

Mortgage applications do not arrive as neat data. They arrive as an email, a payslip, a bank statement and a credit report. Someone has to read them all, copy the figures out, and notice when they disagree. It is slow work, and the mistakes that matter are easy to miss.

02What it does

The agent reads each document and pulls out the figures, noting which document every figure came from. It then looks for trouble: an income the payslip does not support, a car loan the applicant did not mention, or a number that rests only on the applicant’s own word.

03How it works

The AI reads; it does not decide. The approval itself is a fixed rule stored in the database and checked against a policy table, so the same file always gets the same answer and anyone can see why. Any application that is not a clean pass goes to a person, together with a case note the agent has already drafted. Every step is recorded, so you can trace how each figure was found.

04What came out of it

A working demo with eleven checks on what the agent extracts. The write up on GitHub is an honest field report, including where the platform and the model fell short. This is the pattern I suggest to most organisations starting with agents: give AI the reading, keep the decision in rules people can audit.
